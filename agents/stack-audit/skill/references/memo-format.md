# Tool-cut memo format

```
Subject: Recommendation: <action> <tool> before <notice deadline>

Recommendation: <cut | consolidate into X | downsize to N seats>, saving <$> a year.
Why: utilization <x%> (<active> of <purchased> seats), cost per active seat <$>, <n> logins in 30 days.
Overlap: <capabilities> also covered by <tools / agents>.
Condition before acting: <condition from the capability map>.
Side by side: <overlap % and converted accounts at risk, or "not run yet">.
Deadline: notice by <date> (<n> days), renewal <date>.
Owner: <tool owner>. Decision needed from: <budget owner>.
```

Rules: numbers only from the audit, no adjectives about the vendor, one recommendation per memo, and say plainly what is unknown.
