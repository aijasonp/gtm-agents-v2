# Follow-up rules

The job is less admin for sellers, not more noise. Fewer, better nudges.

## What counts as a follow-up item

| Item | Rule |
| --- | --- |
| Overdue task | Open task with a due date before today |
| Missed next step | Open deal whose next-step date has passed |
| No next step | Open deal with no next step written down |
| Going quiet | Open deal with no activity for longer than its stage allows (discovery 21 days, qualification 14, evaluation 10, proposal 7, negotiation and commit 5) |
| Unworked lead | Lead routed to the seller, past its response SLA, with no follow-up sent |
| No recap | Call in the last 3 days with no recap drafted |

## Priority

Higher first: unworked hot leads and missing recaps, then later-stage and larger deals, then the most days overdue.

## No spam

- At most 5 items per seller per day.
- The same item is not repeated within 3 days, unless it gets worse.
- A seller can snooze an item for a number of days.
- Every item comes with one suggested action and a draft when one helps.
