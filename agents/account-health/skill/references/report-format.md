## One customer

```
*Northwind Logistics* | SAVE | risk 100 (at_risk) | expansion 0

Risk: active users -37% (80 to 50); said "We are evaluating alternatives for next year"; champion or sponsor left: Dana Cole

```

## Daily changes

Only what changed since yesterday: new saves, new expansion plays, and customers that entered the renewal window while not healthy. No post when nothing changed.
