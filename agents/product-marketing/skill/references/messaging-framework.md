# Messaging framework

Messaging is built per persona function (sales, revops, executive and so on) and segment
(mid_market or enterprise).

1. **Pain**: the problem in the buyer's words. Source: `company.yaml` value props, refined by
   quotes from calls with this persona.
2. **Outcome**: what changes for them. Source: the matching value prop outcome.
3. **Proof**: approved proof points only. If none fit, the brief says "missing proof" so
   marketing can go get one.
4. **Objections to expect**: the top objection categories on deals where this persona was
   involved, with the prepared response.
5. **Words to use and avoid**: use the buyer's own terms from quotes; avoid hype words (see the
   Copy QA Gate list).

Persona to value prop defaults: sales -> prioritization, revops -> deal_hygiene,
executive -> deal_hygiene, anything else -> the first value prop.
