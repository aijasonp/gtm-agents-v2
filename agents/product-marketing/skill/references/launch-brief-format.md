# Launch brief format

Fill only what is known. Everything else is TODO with the owner who should supply it.

```
Launch brief: <feature>
Audience: <audience>

1. What it is (one sentence)                     TODO: product owner
2. Who it is for and the pain it solves          from company.yaml where it matches
3. What changes for the customer                 from company.yaml value props
4. Proof                                         approved proof points, else TODO
5. Positioning vs competitors                    from company.yaml competitor notes
6. Objections we expect                          from the objection library
7. Launch date, channels, owners                 TODO: marketing
8. Enablement: talk track, demo, FAQ             TODO: enablement
9. Success metric and how we measure it          TODO: product owner
```
