# Summary format

## Slack digest, one block per call

```
*Northwind discovery* (Northwind Logistics, Sam Rivera, 28 min)
Summary: Reps build lists by hand, about 6 hours a week. Pilot first, CFO signs off over 50k.
Next steps: Sam sends pilot plan by Friday; meeting with CFO next week
Flags: none
Competitors: Acme Intel
MEDDPICC evidence: pain, metrics, economic buyer, decision process, champion, competition
```

## CRM note (queued for approval)

```
Call: Northwind discovery (2026-10-20)
Pain: <one line, buyer's words>
Next steps: <bullets with owner and date when said>
Risks: <objections, competitors, missing next step>
MEDDPICC evidence found: <element: short quote>
```

Rules: quote the buyer where possible, no adjectives, no guesses. If the call did not say it, it is not in the note.
